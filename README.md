# Sistema de Controle de Vendas e Estoque
Sistema leve construído em Python (Streamlit + SQLite) para gerenciamento de estoque, com cálculo automático do lucro real (agora incluindo o frete de envio no custo).

## Como rodar localmente
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o app: `streamlit run app.py`
